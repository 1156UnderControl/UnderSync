# Archived Onshape Spikes 1–3

This folder preserves the disposable selection, OAuth, part-resolution, rename, and change-detection spike work that preceded the active UnderSync application.

- `src/`, `public/`, and `test/` contain the original implementation and tests.
- `SPIKES_README.md`, `SPIKE_2_REPORT.md`, and `TEST_REPORT.md` preserve the original instructions and evidence.
- `build/` is the last generated JavaScript output and remains ignored by Git.

Nothing here is part of the active TypeScript build. When Onshape integration work resumes, reuse the evidence deliberately rather than moving these files back wholesale.
