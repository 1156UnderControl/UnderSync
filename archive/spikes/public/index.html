Right Panel extension

Use this Action URL for an Element right panel extension with the Inside Part Studio context:

http://localhost:8000/panel?documentId={$documentId}&workspaceOrVersion={$workspaceOrVersion}&workspaceOrVersionId={$workspaceOrVersionId}&elementId={$elementId}&configuration={$configuration}

Onshape appends default parameters including server. The panel maps workspaceOrVersionId into the required client-message workspaceId field.

Open the panel standalone (context will be empty outside Onshape).
